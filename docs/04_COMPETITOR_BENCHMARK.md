## What to learn from *quality*, not subject
- Stateful choice chain with actual consequences: late changes invalidate readiness/approval.
- Faults have readable cause/repair feedback (mass, budget, thermal, battery, peak power).
- Useful companion, voiced/captioned guidance, concise full-viewport UI.
- Saved games, restart, demo mode separate from normal, mobile-first controls.
- Guided vs challenge modes, contextual hints, stage retry instead of dead end.
- Documentation and browser screenshots as acceptance evidence.
