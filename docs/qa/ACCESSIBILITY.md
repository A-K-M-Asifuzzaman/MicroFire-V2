# Accessibility foundation

Checked in Chromium desktop/mobile emulation: keyboard-visible skip link, semantic header/nav/main/footer/headings, readable source text without JavaScript, disabled Coming Soon controls, mobile dossier without horizontal overflow, reduced-motion mode and actual screenshots. No animations or WebGL are required in P0. Source condition labels are human-readable.

Not a WCAG certification: full contrast audit, screen-reader testing, zoom/reflow matrix, real assistive switches, translated content and all future game controls remain untested. Future 2D/keyboard game views must dispatch the same shared game actions as 3D.
