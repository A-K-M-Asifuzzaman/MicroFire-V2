# microfire-science-integrity

Check every proposed finding against source ID + original URL and where available page/test. Separate observed/derived/interpretation/not established. No fake study counts or fire risk. For source mismatch show dimensions. Test unsupported Moon/Mars queries by abstention. Do not treat illustrative 3D animation as physics prediction. Preserve attribution and license; report actual evidence and limitations.

Refer to `docs/00_REPO_RULES.md` and `docs/03_RELEASE_STAGES_COMING_SOON.md` before action. Work ONLY in MicroFire-V2 and record evidence of completion.
