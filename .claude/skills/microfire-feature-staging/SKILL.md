# microfire-feature-staging

Inspect actual implementation, tests and screenshots. Only mark Available after implementation and working E2E/browser verification. Preview must be clearly limited, Coming Soon disabled/info only, Blocked shows reason, Locked means built but progression-restricted. Do not invent delivery date or turn dead button into claimed function. Update docs/IMPLEMENTATION_STATUS.md, routes registry and release notes with exact PR/SHA.

Refer to `docs/00_REPO_RULES.md` and `docs/03_RELEASE_STAGES_COMING_SOON.md` before action. Work ONLY in MicroFire-V2 and record evidence of completion.
